## 📌 About the Project

The **AI Powered Career Guidance System** is an intelligent career guidance platform designed to help students identify suitable career paths based on their interests, skills, assessment results, and career preferences.

The system provides:

* 🤖 AI-powered career recommendations
* 📊 Career assessment and analysis
* 🧭 Personalized career roadmaps
* 👨‍🏫 Mentor guidance
* 📚 Learning resources and courses
* 💼 Career and skill information
* 📈 Personalized progress tracking
